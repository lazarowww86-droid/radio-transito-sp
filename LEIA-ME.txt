RÁDIO TRÂNSITO SP — PREVISÃO DO TEMPO: SÃO PAULO E GUARULHOS

COMO ATUALIZAR
1. Extraia 05-ATUALIZACAO-PREVISAO-DO-TEMPO.zip.
2. Abra a página principal do repositório radio-transito-sp no GitHub.
3. Clique em Add file > Upload files.
4. Envie TODOS os arquivos extraídos diretamente na raiz do repositório, substituindo os atuais, e confirme em Commit changes.
5. Após a publicação, recarregue o site: Ctrl+F5 no computador; no celular, recarregue a página e reabra o aplicativo.

Este pacote contém só arquivos pequenos do site. A pasta media atual, com os áudios leves, já serve para esta atualização. O projeto completo atualizado também está disponível em RADIO-TRANSITO-SP-LEVE.zip.

O QUE ENTRA NA RÁDIO
- Painel de São Paulo e Guarulhos com temperatura estimada, sensação térmica, condições do céu, mínima, máxima e chance de chuva.
- Durante o dia, mostra mínima e máxima de hoje. A partir das 18h, mostra a previsão de amanhã.
- Boletim falado das duas cidades a cada 30 minutos durante a escuta. O primeiro boletim automático entra após cerca de 30 minutos ouvindo; o botão OUVIR BOLETIM permite ouvir antes.
- O botão de seta atualiza os dados do painel.
- Usa a mesma voz da hora certa, em frases curtas.

CONTINUIDADE
A consulta acontece enquanto a programação toca. O podcast só pausa quando os dados estão prontos para leitura. Depois do boletim, volta ao mesmo ponto. Pausar ou avançar cancela a fala. Pausar durante a consulta também evita iniciar a voz depois.

Se outro aviso estiver no ar, o boletim automático espera. Se a consulta falhar ou os dados estiverem vencidos, a rádio segue sua programação. Sem conexão, os áudios previamente armazenados continuam disponíveis; a previsão depende de acesso à fonte.

FONTE
Open-Meteo, com dados estimados por modelos meteorológicos. A chance exibida é o maior percentual previsto para os próximos três horários futuros disponíveis, dentro de três horas. Não é uma soma das probabilidades.
https://open-meteo.com/en/docs
https://open-meteo.com/en/terms

A API gratuita é destinada a uso não comercial. Os créditos à Open-Meteo e à licença CC BY 4.0 estão no painel. Não é necessário cadastrar chave de API para este uso. Publicidade ou assinaturas exigem rever os termos da fonte.
